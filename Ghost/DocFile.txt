### 2026-04-05 — Исправление критичных багов и переименование

#### 1. Переименование проекта
- **Namespace**: `SchoolTaskBazaar` → `Ghost` (все файлы)
- **Assembly/RootNamespace**: `Ghost` (Ghost.csproj)
- **JWT Issuer/Audience**: `SchoolTaskBazaar`/`SchoolTaskBazaarUsers` → `Ghost`/`GhostUsers`
- **База данных**: `schoolbazaar.db` → `ghost.db`
- **Админка**: заголовок "SchoolTaskBazaar" → "Ghost"
- **Миграции**: обновлены namespace в InitialCreate.Designer.cs и AppDbContextModelSnapshot.cs

#### 2. CryptoCloudService.cs — исправлена заглушка
- **Было**: `CheckPaymentStatusAsync()` всегда возвращал `true` (TODO)
- **Стало**: Реальная проверка статуса через CryptoCloud API (`/invoice/info`)
- **Fallback**: если API ключи не настроены — возвращает `true` (режим разработки)
- **CreateInvoiceAsync**: если API ключи не настроены — возвращает демо-ссылку

#### 3. CryptoCloudService.cs — thread-safety HttpClient
- **Было**: `_httpClient.DefaultRequestHeaders.Clear()` и `.Add()` — не thread-safe
- **Стало**: `HttpRequestMessage` с per-request headers

#### 4. AdminActionRequest.cs — исправлен тип TargetId
- **Было**: `int? TargetId` — не работало для бана (phraseHash — строка)
- **Стало**: `int? TargetTaskId` (для удаления заданий) + `string? TargetPhraseHash` (для бана)

#### 5. AdminController.cs — исправлен бан пользователей
- **Было**: `request.TargetId?.ToString()` — конвертировало int в string
- **Стало**: `request.TargetPhraseHash` — прямая передача phraseHash
- **Добавлено**: endpoint `GET /api/Admin/complaints` — список ожидающих жалоб
- **Добавлено**: endpoint `POST /api/Admin/resolve-complaint` — рассмотрение жалобы

#### 6. Program.cs — зарегистрирован AdminAuthMiddleware
- **Было**: Middleware существовал, но не был добавлен в pipeline
- **Стало**: `app.UseMiddleware<AdminAuthMiddleware>()`
- **JWT fallback**: единый ключ `"GhostSuperSecretKeyForJWT2024!LongEnough32Chars"`

#### 7. AuthController.cs — исправлены JWT ключи и race condition
- **Было**: fallback ключ `"supersecretkey"` (отличался от Program.cs)
- **Стало**: exception если JWT ключ не настроен (без fallback)
- **Race condition**: добавлена транзакция + атомарный `CountAsync()` для первого пользователя-админа

#### 8. NicknameGenerator.cs — thread-safe Random
- **Было**: `private static readonly Random _random = new()` — не thread-safe
- **Стало**: `Random.Shared.Next(1000, 9999)` — thread-safe (.NET 6+)

#### 9. Админ-панель (wwwroot/admin/index.html)
- **Было**: `API_URL = 'http://localhost:5274'` — захардкожен
- **Стало**: `window.location.origin` — автоопределение
- **Добавлено**: `loadComplaints()` — загрузка и отображение жалоб
- **Добавлено**: `resolveComplaint()` — кнопка рассмотрения жалобы
- **Исправлено**: `banUser()` → `targetPhraseHash` вместо `targetId`
- **Исправлено**: `deleteTask()` → `targetTaskId` вместо `targetId`
- **Добавлено**: статистика deals и complaints (пока заглушка)

### API Эндпоинты

#### Auth
- `POST /api/Auth/login` — вход/регистрация (фраза → токен + ник + isAdmin)

#### Tasks
- `GET /api/Tasks` — список открытых заданий
- `GET /api/Tasks/{id}` — одно задание
- `POST /api/Tasks` — создать задание
- `POST /api/Tasks/{id}/take` — взять в работу
- `POST /api/Tasks/{id}/complete` — завершить

#### Deals
- `POST /api/Deals` — создать сделку (эскроу)
- `POST /api/Deals/{id}/confirm` — подтвердить выполнение
- `POST /api/Deals/{id}/dispute` — открыть спор
- `GET /api/Deals/my` — мои сделки

#### Admin (только isAdmin=true)
- `GET /api/Admin/users` — все пользователи
- `GET /api/Admin/tasks` — все задания
- `GET /api/Admin/complaints` — ожидающие жалобы
- `POST /api/Admin/ban` — забанить (targetPhraseHash)
- `POST /api/Admin/delete-task` — удалить задание (targetTaskId)
- `POST /api/Admin/resolve-complaint` — рассмотреть жалобу
- `POST /api/Admin/start-poll` — запустить опрос
- `POST /api/Admin/end-poll` — завершить опрос
- `POST /api/Admin/enable-monetization` — включить комиссию 5%

#### Poll
- `GET /api/Poll/active` — активный опрос
- `POST /api/Poll/{pollId}/vote` — проголосовать
